# SUBSISTENCE — Альфа 1.2.1

2D survival-хоррор с боковым видом и атмосферой Backrooms. Целевая версия Unity — **2022.3.62f2**. Это исходный Unity-проект; готового `.exe` в этом релизе нет. Браузерная игра не заявляется, отдельный сайт-бриф из 20 вопросов не менялся.

## Запуск в Unity

1. Открой `UnityProject/` в Unity Hub с Editor **2022.3.62f2**.
2. Дождись импорта. При первом открытии Editor-скрипт создаст тестовую сцену `Assets/Scenes/FieldTest.unity`.
3. Нажми **Play ▶** и в меню выбери **«НАЧАТЬ ИГРУ» → локальный сектор → «НАЧАТЬ ЛОКАЛЬНУЮ ЭКСПЕДИЦИЮ»**. Действующих онлайн-серверов нет.

## Содержимое альфы

- Чистый 2D side-view: ортографическая камера, 2D-коллайдеры и пиксельные спрайты.
- Четыре вариативных локальных сектора Backrooms с индустриальными деталями, плиткой, дверьми, трубами и тёплым светом.
- Отдельные редактируемые модели персонажей и предметов в `UnityProject/ArtSource/individual_models.piskel`; игровой атлас — `Assets/Resources/PixelArt/individual_models.png`.
- Rust-подобный HUD, инвентарь, экипировка, лут-контейнеры, крафт и противник.
- Музыка, эмбиент и звуковые эффекты; уровень громкости музыки увеличен.

## Управление

- **A / D** или **← / →** — движение; **Space / W / ↑** — прыжок.
- **E** — взаимодействие; **Q** — атака; **F** — фонарь.
- **1–6** или колёсико мыши — выбор пояса; **H** — быстрое лечение; **C** — быстрый крафт бинта.
- **Tab / I** — инвентарь; **Esc** — пауза/закрытие.

Полная инструкция, крафт и шаги сборки Windows — [`UnityProject/README.md`](UnityProject/README.md). Изменения: [`UnityProject/CHANGELOG.md`](UnityProject/CHANGELOG.md).

**Проверка:** Unity Editor недоступен в среде выпуска. Импорт, компиляция, Play Mode и Windows-сборка не проверены; релиз содержит исходники, не исполняемый файл.

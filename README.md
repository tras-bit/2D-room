# SUBSISTENCE — Альфа 1.0.0

2D survival-хоррор с боковым видом, пиксельной графикой и атмосферой выживания. Целевая версия Unity — **2022.3.62f2**. Браузерной версии игры нет; сайт из 20 вопросов оставлен только как отдельный бриф.

## Запустить игру в редакторе

1. Открой `UnityProject/` через Unity Hub с Editor **2022.3.62f2**.
2. Дождись импорта. При первом открытии проект создаст сцену `Assets/Scenes/FieldTest.unity`.
3. Открой эту сцену, если она не загрузилась автоматически, и нажми **Play ▶** в верхней панели Unity.
4. В окне Game выбери **«НАЧАТЬ СМЕНУ»**.

Для тестирования **2D не запускается по-другому, чем 3D**: та же кнопка Play запускает текущую сцену прямо в Unity Editor. Не нужно вручную ставить персонажа, делать 3D-камеру или собирать сцену. Подробная инструкция, клавиши и сборка Windows `.exe` — [`UnityProject/README.md`](UnityProject/README.md).

## Что есть в альфе

Меню и настройки, боковое движение и прыжок, поиск припасов, здоровье/голод/жажда, преследователь, перевязка, условие выхода, покадровая пиксельная анимация, оригинальная музыка, эмбиент и звуковые эффекты. История версий: [`UnityProject/CHANGELOG.md`](UnityProject/CHANGELOG.md); технические решения и проверенные ссылки: [`UnityProject/RESEARCH.md`](UnityProject/RESEARCH.md).

# SUBSISTENCE — Альфа 1.1.1

2.5D survival-хоррор с боковым видом и 2D-физикой, объёмным окружением и атмосферой Backrooms. Целевая версия Unity — **2022.3.62f2**. Браузерной версии игры нет; сайт из 20 вопросов оставлен только как отдельный бриф.

## Запустить игру в редакторе

1. Открой `UnityProject/` через Unity Hub с Editor **2022.3.62f2**.
2. Дождись импорта. При первом открытии проект создаст сцену `Assets/Scenes/FieldTest.unity`.
3. Открой эту сцену, если она не загрузилась автоматически, и нажми **Play ▶** в верхней панели Unity.
4. В окне Game выбери **«НАЧАТЬ ИГРУ» → локальный сектор → «НАЧАТЬ ЛОКАЛЬНУЮ ЭКСПЕДИЦИЮ»**. Онлайн-серверов в прототипе нет.

Для тестирования **2D не запускается по-другому, чем 3D**: та же кнопка Play запускает текущую сцену прямо в Unity Editor. Не нужно вручную ставить персонажа или собирать сцену. Подробная инструкция, клавиши и сборка Windows `.exe` — [`UnityProject/README.md`](UnityProject/README.md).

## Что есть в альфе

Главное меню по новым референсам с кинематографическим фоном Backrooms, четыре локальных сектора, боковой игровой процесс на 2D-физике с объёмными моделями, инвентарь и экипировка с отображением одежды на персонаже, контейнеры трёх уровней, верстаки, противник и базовые ресурсы выживания. Вкладки настроек включают графику, звук, управление и интерфейс. История версий: [`UnityProject/CHANGELOG.md`](UnityProject/CHANGELOG.md); технические решения и ссылки на документацию: [`UnityProject/RESEARCH.md`](UnityProject/RESEARCH.md).

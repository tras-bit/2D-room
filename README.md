# SUBSISTENCE — Unity field test 001

Разработка **2D survival-хоррора** для Unity **2022.3.62f2**. В проекте есть Unity-основа игры с меню, выживанием, процедурными pixel-art спрайтами/анимацией и авторским синтезированным звуком. Отдельно сохранён запрошенный русскоязычный 20-вопросный бриф; браузерной версии игры больше нет.

## Unity-проект

Откройте `UnityProject/` через Unity Hub с Editor **2022.3.62f2**. На первом импорте проект создаст launch-сцену `Assets/Scenes/FieldTest.unity` и добавит её в список сборки. Нажмите **Play**.

Подробно: [`UnityProject/README.md`](UnityProject/README.md). Технические решения и ссылки на документацию: [`UnityProject/RESEARCH.md`](UnityProject/RESEARCH.md).

## Бриф из 20 вопросов

Откройте `index.html` или запустите из корня репозитория:

```bash
python3 -m http.server 8000
```

Ответы автоматически сохраняются локально в браузере. Есть удобное копирование каждого ответа и всего брифа, экспорт `.txt`, резервная копия `.json` и её импорт. Ответы не отправляются на сервер.

## 2D-инструменты

Для самостоятельной работы над пиксель-артом подойдут **Krita** (рисование) или **Aseprite** (пиксель-арт); для 2D-игры Blender не обязателен. В этой среде Unity Editor и графические программы не установлены — проект и исходные ассеты подготовлены, но для запуска Unity-проекта понадобится Unity Hub/Editor.

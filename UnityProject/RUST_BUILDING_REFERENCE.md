# Rust-style construction reference

Справка по строительной петле Rust для будущей адаптации к боковой 2D-игре. Это дизайн-ориентир, а не утверждение, что эта механика уже реализована в SUBSISTENCE.

## Что важно в Rust

1. **Building Plan** — отдельный инструмент для выбора и установки строительных частей. В официальной вики указаны стоимость крафта 20 дерева и отсутствие требования к верстаку.
2. **Постройка появляется поэтапно.** Игрок сначала размечает фундамент/стену/проём/пол/крышу; затем улучшает секции материалом. Временная слабая стадия позволяет сначала собрать планировку.
3. **Hammer** — отдельный инструмент для улучшения и ремонта уже поставленных частей, а также взаимодействия с развёрнутыми объектами.
4. **Tool Cupboard (TC)** задаёт строительные права и обслуживание базы. Поставивший TC авторизуется автоматически; связанные фундаменты формируют зону привилегии. Запас в TC оплачивает upkeep материалами конструкции; при нехватке материалов строение начинает разрушаться. Раздельные здания требуют собственного связанного TC.
5. **Опора и стабильность** ограничивают висящие/неподдержанные конструкции; размещение не должно быть свободным рисованием без геометрических правил.

## Перенос в SUBSISTENCE

- Сохраняем обязательный **боковой 2D-вид**. Строительные части должны ставиться по читаемой сетке и иметь понятные точки привязки: фундамент, стена, дверной проём и перекрытие/крыша.
- **Стартовая база не генерируется.** Нет готового дома, поставленного верстака или домашнего ящика. Игрок добывает материалы и сам размещает постройку.
- План размещает временную базовую версию детали; молоток улучшает/чинит её; проверка опоры запрещает невозможные пролёты.
- Хранилище и верстак — это предметы/объекты, которые игрок должен будет изготовить и поставить, а не стартовый декор уровня. Три уже имеющихся ящика на Level 0 остаются отдельными мировыми лут-кейсами, не хранилищем базы.
- Оригинальные числовые цены, HP и таймеры Rust не копируем автоматически: баланс нужно отдельно настроить под одиночную 2D-игру. Сетевая авторизация в проекте не нужна; если сохраняем роль TC, она отвечает за право строить и обслуживание собственной базы.

## Текущее состояние

На текущем этапе из старта удалено автоматическое появление двух `WorkbenchStation`. В `WorldBuilder2D` строится только окружение, а не база игрока. Сам цикл «план → размещение → молоток/улучшение → TC/upkeep» ещё предстоит реализовать.

# SUBSISTENCE — Unity field test 001

Целевой редактор: **Unity 2022.3.62f2**. Релиз проверен по [официальной странице Unity](https://unity.com/releases/editor/whats-new/2022.3.62f2). Это начальный Unity-проект, не браузерная игра. Он создаёт поле, спрайты и игровые системы кодом; внешние модели и платные пакеты не нужны, потому что игра 2D.

## Запуск

1. Установи Unity Hub, затем [Unity Editor **2022.3.62f2** через официальный Unity Hub](unityhub://2022.3.62f2/7670c08855a9) и модуль сборки для своей ОС.
2. В Unity Hub выбери **Add / Open project** и укажи эту папку `UnityProject`.
3. Дождись импорта. Скрипт Editor автоматически создаст и сохранит сцену `Assets/Scenes/FieldTest.unity`, а также добавит её в Build Settings.
4. Открой сцену `FieldTest` и нажми **Play**.

При первом открытии Unity должен быть подключён к сети, чтобы Package Manager загрузил штатные модули из `Packages/manifest.json`. Сам Unity Editor в этой среде не установлен, поэтому импорт и запуск в редакторе ещё не проверялись.

## Уже собрано

- Главное меню, экран управления, настройки громкости и полноэкранного режима, пауза, поражение и победа.
- Side-scroller: движение, прыжок, фонарик, сбор металла/ткани/еды/воды, шкалы голода/жажды/здоровья.
- Преследователь с патрулём, агро, атакой и оглушением; перевязка за две ткани; выход с условиями.
- Рисованные кодом точечно-фильтрованные спрайты героя, существа, припасов, укрытий и декора.
- Покадровые циклы idle/walk/jump/attack/hurt и анимация преследователя.
- Авторские сгенерированные WAV в `Assets/Resources/Audio`: музыкальная тема, эмбиент и эффекты предметов, шагов, атаки, попадания и интерфейса. Исходник генератора — `Tools/generate_audio.py`.
- Прогресс Unity не генерирует никакой web-игры.

## Управление

- **A / D** или **← / →** — движение
- **Space / W / ↑** — прыжок
- **E** — поднять предмет / использовать выход
- **Q** — отбросить преследователя
- **C** — перевязка (2 ткани)
- **F** — включить / выключить фонарик
- **Esc** — пауза

Собери три припаса, включая хотя бы одну единицу металлолома, и активируй выход. Это стартовый игровой срез: после твоих ответов на вопросы брифа можно точнее определить биом, сюжет, противников, мультиплеер и правила смерти.

# SUBSISTENCE — Альфа 1.2.1

**Целевая версия Unity: 2022.3.62f2.** Это Unity-проект, не браузерная игра. Игровой мир построен в чистом боковом 2D-виде: ортографическая камера, 2D-физика и пиксельные спрайты окружения и моделей. HUD вдохновлён Rust: шесть слотов пояса, полосы состояния и компас. Онлайн-серверов нет; сектора запускаются локально.

## Запуск в Unity Editor

1. Установи Unity Hub и [Unity Editor 2022.3.62f2](unityhub://2022.3.62f2/7670c08855a9).
2. В Unity Hub выбери **Add → Add project from disk** и укажи папку `UnityProject`.
3. Дождись импорта пакетов из `Packages/manifest.json`. При первом открытии Editor-скрипт создаёт сцену `Assets/Scenes/FieldTest.unity` и добавляет её в Build Settings.
4. Нажми **Play ▶** и открой вкладку **Game**. В главном меню выбери **«НАЧАТЬ ИГРУ» → локальный сектор → «НАЧАТЬ ЛОКАЛЬНУЮ ЭКСПЕДИЦИЮ»**. Действующих онлайн-серверов в прототипе нет.

Сцена, персонаж, комнаты и контейнеры собираются игровым кодом при запуске. Перетаскивать объекты на сцену вручную не нужно.

## Игровой цикл

- Выбери один из четырёх секторов; это **локальная одиночная экспедиция**, а не список действующих сетевых серверов.
- Обыщи контейнеры уровней I–III. Взаимодействие — **E**; содержимое и качество добычи различаются по уровню.
- Собирай ресурсы, еду, воду, лекарства, оружие, броню и чертежи. В рюкзаке 30 ячеек (6 × 5), отдельно — шесть слотов пояса и пять слотов экипировки.
- Переноси и разделяй стопки мышью, используй Shift для быстрого перемещения, надевай экипировку и выбрасывай ненужные предметы.
- Чертежи сначала нужно изучить из инвентаря. Рецепты проверяют нужные предметы, уровень верстака и открытые чертежи; бинт доступен без верстака.
- Нажми **H** для быстрого применения бинта/аптечки: сначала используется медицинский предмет активного слота, затем предметы пояса и рюкзака.
- Для завершения смены осмотри три ящика, найди карту доступа в контейнере уровня III и доберись до выходного люка.

## Управление

- **A / D** или **← / →** — движение
- **Space / W / ↑** — прыжок
- **E** — открыть ящик / подобрать предмет / проверить выход
- **Q** — ближняя атака или выстрел из выбранного оружия
- **F** — фонарь
- **1–6** или **колесо мыши** — выбрать слот пояса
- **H** — быстро использовать бинт или аптечку
- **C** — быстрый крафт бинта (нужно 2 ткани)
- **Tab / I** — инвентарь, экипировка, добыча и меню крафта
- **ЛКМ** — взять или перенести предмет
- **Shift + ЛКМ** — быстрый перенос
- **ПКМ** — разделить стопку / положить одну единицу
- **Esc** — пауза или закрытие инвентаря

## Сборка для Windows

1. Установи модуль **Windows Build Support** через Unity Hub.
2. В Unity открой **File → Build Settings**, проверь, что `FieldTest` есть в **Scenes In Build**.
3. Выбери **PC, Mac & Linux Standalone → Windows → x86_64**, затем нажми **Build**.

## Структура проекта

- `Assets/Scripts/WorldBuilder2D.cs`, `PixelArtFactory.cs`, `CharacterVisual2D.cs` — построение side-view мира и игровые спрайты.
- `Assets/Resources/PixelArt/individual_models.png` — отдельный атлас выжившего, наблюдателя, двери и предметов; он собран в проект `ArtSource/individual_models.piskel` и используется игровыми моделями.
- `Assets/Scripts/CameraFollow2D.cs`, `PixelFrameAnimator.cs` — ортографическая камера и спрайтовая анимация.
- `Assets/Scripts/InventorySystem.cs`, `GameHUD.cs` — 30 ячеек рюкзака, пояс из шести ячеек, чертежи, крафт и Rust-подобный HUD.
- `Assets/Resources/Art/menu_backrooms.png` и `menu_maintenance_backrooms.png` — полноэкранные атмосферные фоны для главного меню/прочих экранов и настроек/выбора сектора. Остальные старые изображения в `Assets/Resources/Art/` мир не загружает.
- `Assets/Resources/Audio/` — музыка и звуковые эффекты.
- `Assets/Editor/FieldTestProjectSetup.cs` — создание стартовой сцены и установка версии приложения при первом открытии.
- `Tools/generate_pixel_assets.py` — подготовка отдельного арт-листа и Piskel-проекта; `Tools/piskel_preview_server.py` — локальный просмотр Piskel-проекта, если собран редактор в `.tools/Piskel/`.
- `RESEARCH.md` — технические решения и ссылки на документацию Unity.
- Для ручного редактирования открой `ArtSource/individual_models.piskel` в бесплатном [Piskel](https://www.piskelapp.com/) или используй его [исходный код](https://github.com/piskelapp/piskel).

**Ограничение проверки:** Unity Editor недоступен в среде разработки. Импорт проекта, компиляция скриптов, Play Mode и сборка `.exe` здесь не запускались; их необходимо проверить в Unity 2022.3.62f2.

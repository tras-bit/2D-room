# SUBSISTENCE — альфа 1.0.0

**Целевая версия Unity: 2022.3.62f2.** Версия есть на [официальной странице Unity](https://unity.com/releases/editor/whats-new/2022.3.62f2). Это Unity-проект, не браузерная игра. Игра 2D, поэтому отдельную 3D-сцену или управление 3D-камерой настраивать не нужно.

## Как запустить игру в Unity Editor

1. Установи Unity Hub, затем [Unity Editor 2022.3.62f2](unityhub://2022.3.62f2/7670c08855a9).
2. В Unity Hub нажми **Add → Add project from disk** и выбери папку `UnityProject` из этого репозитория.
3. При первом открытии дождись импорта. Нужен интернет для загрузки пакетов из `Packages/manifest.json`. Editor-скрипт проекта автоматически создаст сцену `Assets/Scenes/FieldTest.unity` и добавит её в Build Settings.
4. Если сцена открылась автоматически — переходи дальше. Иначе в окне **Project** открой `Assets → Scenes → FieldTest` двойным щелчком.
5. Нажми треугольную кнопку **Play ▶** наверху Unity. Если видишь окно **Scene**, переключись на вкладку **Game** — именно там идёт игра. Дождись главного меню и выбери мышью **«НАЧАТЬ СМЕНУ»**.

**Для 2D запуск такой же, как для 3D:** кнопка **Play** запускает текущую сцену внутри редактора. В этом проекте игрок, окружение, камера и стартовая сцена собираются при запуске; не нужно перетаскивать персонажа на уровень вручную. Основа игрового процесса — 2D-перемещение влево/вправо, прыжок и взаимодействие.

## Как собрать отдельный `.exe` для Windows

1. В Unity Hub у установленного редактора открой меню **⋯ → Add modules** и поставь **Windows Build Support**.
2. В Unity открой **File → Build Settings**. Сцена `FieldTest` должна быть в списке **Scenes In Build** — проект добавляет её автоматически.
3. Выбери **PC, Mac & Linux Standalone → Windows → x86_64**. Если платформа ещё не установлена, Unity предложит добавить модуль через Hub.
4. Нажми **Build**, выбери папку назначения и дождись создания приложения.
5. Запусти созданный `SUBSISTENCE.exe`. Это уже самостоятельная сборка; открывать её через Unity Hub не требуется.

Unity описывает [Play Mode](https://docs.unity3d.com/2022.3/Documentation/Manual/ConfigurableEnterPlayMode.html) как запуск проекта прямо внутри Editor, а [Build Settings](https://docs.unity3d.com/2022.3/Documentation/Manual/BuildSettings.html) — как настройку сцен и сборки для выбранной платформы.

## Управление в игре

- **A / D** или **← / →** — ходьба
- **Space / W / ↑** — прыжок
- **E** — подобрать припас / использовать выход
- **Q** — оттолкнуть преследователя
- **C** — перевязать себя (нужно 2 ткани)
- **F** — включить/выключить фонарь
- **Esc** — пауза

Собери три припаса, включая металлолом, и активируй выход. В альфе есть главное меню, настройки громкости и полноэкранного режима, пауза, экраны победы/поражения, здоровье, голод и жажда, один противник, а также авторская процедурная пиксельная графика и оригинальные музыкальные/звуковые WAV.

## Где находятся исходники

- Игровой код: `Assets/Scripts/`

- История версий: `CHANGELOG.md`
- Технические решения и ссылки на официальную документацию: `RESEARCH.md`
